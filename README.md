## 🛠️ Cài đặt

### Deploy trên GitHub Pages

1. Fork repository này
2. Vào Settings > Pages
3. Chọn Source: Deploy from a branch
4. Chọn Branch: `main` và folder: `/ (root)`
5. Click Save
6. Đợi vài phút để GitHub Pages deploy

### Chạy local

```bash
# Clone repository
git clone https://github.com/Moseyuh333/simple_phishing.git

# Mở file index.html bằng browser
# Hoặc dùng Live Server trong VS Code
```

## 🔒 Bảo mật

Trang web này:
- ✅ Không thu thập dữ liệu thực
- ✅ Không gửi thông tin đến server
- ✅ Chỉ là HTML/CSS/JS tĩnh
- ✅ Không có backend
- ✅ Mục đích giáo dục thuần túy

## 📚 Kiến thức rút ra

Người dùng cần:
1. ✅ Luôn kiểm tra URL trước khi nhập thông tin
2. ✅ Xác minh chứng chỉ SSL (HTTPS)
3. ✅ Không click vào link lạ
4. ✅ Cẩn thận với email/tin nhắn đáng ngờ
5. ✅ Bật 2FA (Two-Factor Authentication)
